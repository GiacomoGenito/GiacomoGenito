# Hola, soy Giacomo 👋

**Desarrollador web en Madrid · WordPress · Email HTML · Frontend**

Llevo desde 2017 construyendo webs y plantillas de email que funcionan en el mundo real. Ahora estoy llevando mi stack a React y TypeScript.

- 📧 **Email HTML:** 5 años maquetando newsletters para un gran retailer español. Son plantillas responsive que tienen que funcionar en Gmail, Outlook y Apple Mail, se publican en Salesforce Marketing Cloud y se entregan en 24 h desde el mockup.
- 🧩 **WordPress:** temas a medida, plugins, Custom Post Types, ACF, WooCommerce, WPML y Gutenberg. Muchas webs freelance desde 2020.
- 📍 **Landings para negocios locales:** páginas rápidas con SEO on-page bien estructurado para sectores muy competidos (fontanería, cerrajería).
- 🎓 **Docencia:** profesor de Maquetación Web (HTML, CSS, Flexbox, Grid y accesibilidad) en un máster Full Stack.
- 🌱 **Aprendiendo ahora:** React, TypeScript y bloques de Gutenberg.
